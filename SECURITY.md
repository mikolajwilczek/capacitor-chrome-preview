# Security Policy

## Reporting

Do not open a public issue for a suspected vulnerability or include private
target URLs, profile contents, cookies, credentials, or third-party code in a
report.

Use GitHub's private vulnerability-reporting form:

<https://github.com/mikolajwilczek/capacitor-chrome-preview/security/advisories/new>

Include the tested commit, macOS and Chrome versions, the affected command, and
a minimal generic reproduction. This early prototype has no published npm
package or production support promise.

## Supported Version

Security fixes apply to the current `master` branch until the project begins
publishing versioned releases.
